### 👨‍💻 About Me

I'm **Majid Allahverdi (MJ)** — a Senior Full-Stack Engineer with **14+ years of professional experience** designing and shipping production-grade systems across healthcare, fintech, and SaaS.

I specialize in **.NET, Azure, and clean, maintainable architecture** — from greenfield APIs to complex distributed systems. I care deeply about performance, code quality, and building software that scales without becoming a maintenance burden.

- 🏗️ Currently building **[Beeplife](https://github.com/devwithmj/Beeplife_API)** — a cloud-native healthcare platform (.NET 8 Web API + Flutter + Azure)
- 🤖 Exploring **AI/LLM tooling** — see [`llm-token-formats-benchmark`](https://github.com/devwithmj/llm-token-formats-benchmark) & [`n8n-nodes-json-sanitizer`](https://github.com/devwithmj/n8n-nodes-json-sanitizer)
- 📦 Open-source contributor: [`Block.IO.Core`](https://github.com/devwithmj/Block.IO.Core), [`UniversalNotifier.NET`](https://github.com/devwithmj/UniversalNotifier.NET)
- 💡 Interests: Clean Architecture, CQRS, DDD, cloud cost optimisation, and developer tooling
- 📫 Reach me at **majidalahverdi@gmail.com** or on [LinkedIn](https://www.linkedin.com/in/majid-av/)
